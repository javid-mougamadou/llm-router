LLM Router

Lightweight FastAPI proxy that routes Anthropic and OpenAI API requests to AWS Bedrock. Per-user budget management, API key authentication, usage tracking and web dashboards.

View on GitHub Features

Features

Everything you need to proxy LLM requests with control

Dual API compatibility

/v1/messages (Anthropic) and /v1/chat/completions (OpenAI) — use either format, same backend.

Streaming support

Server-Sent Events streaming for both API formats with real-time token delivery.

Budget management

Per-user monthly and daily budgets with automatic spend tracking and auto-reset.

API key auth

Generate multiple keys per user, enable/disable or revoke anytime.

Usage tracking

Token counts and cost per request, per user, per model with monthly history archival.

Web dashboards

Admin UI to manage users, keys, budgets. User UI for self-service budget and usage view.

Dark / Light mode

Theme toggle with localStorage persistence across all dashboards.

Secure by default

PBKDF2-SHA256 passwords, HMAC-SHA256 JWT sessions, SQLite WAL mode for concurrent reads.

Quick Start

# Clone and setup git clone https://github.com/javid-mougamadou/llm-router.git cd llm-router cp Dockerfile.example Dockerfile cp docker-compose.example.yml docker-compose.yml cp .env.example .env # Run docker compose up dev # Open dashboards open http://localhost:4000/admin-ui open http://localhost:4000/user-ui
